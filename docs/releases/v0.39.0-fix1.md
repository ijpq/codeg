# CodeG v0.39.0-fix1

The conversation-wide deliverables list is available again in **Right sidebar →
Session Details → All deliverables** (简体中文：**右侧栏 → 会话详情 → 全部产物**).
The sidebar migration previously hid the transcript entry without providing a
replacement. Existing deliverable records remain the source of the restored list.

Expand the entry to browse persisted outputs across the conversation, with file
filters, versions, 25-item history pages and existing individual/batch actions.
The list fits narrow panes, retains keyboard focus and clears file selections
when switching conversations. Hidden or collapsed panes do not load history.
Per-reply outputs remain available.

Based on upstream **v0.39.0** (`bed8931485d2de6ab65c83e182fbd4a79c72e12b`).
Retains the prior ordinary task duration correction, native Direct / Plan / Goal
controls and virtualized scrolling behavior. No new timing panel or model-output
changes are introduced by this fix.

The two independent same-day historical migrations are registered in name order
for upstream schema-version checks. All released migration names and SQL files
are preserved, so already applied migrations retain their identities.

The release workflow runs lint, unit tests, static export, Rust tests and Clippy
before tagging. Both Windows packages then undergo resource/dependency/migration
checks; isolated Windows runners install, start and upgrade Setup with retained
data, and exercise actual Setup WebView2 and Server Web pages including this list.
Draft assets are verified before publication and downloaded again afterwards.

Assets: Windows x64 Setup and Windows x64 Server ZIP, each with SHA256. Server
includes the matching `codeg-mcp`, CLI companion and pinned native Codex runtime.
