# Codeg v0.23.2

## Upstream sync, reliable remote prompts, and accurate outputs

Codeg v0.23.2 rebases the custom distribution onto upstream v0.23.1 while
preserving and strengthening its remote-session and deliverable workflows.

- **Upstream v0.23.1 is fully integrated.** This release includes work tasks,
  custom agents and skills, linked workspace folders, the latest split/tiled
  conversation UI, and the current agent compatibility updates.
- **Remote text prompts reach the agent reliably.** The client waits for its
  event stream before sending, restores stale ACP connections, and retries only
  deterministic connection loss with the same idempotent message id. Ambiguous
  timeouts are reconciled instead of resent, preventing duplicate prompts.
- **Large images no longer inherit the old upload ceiling.** Browser uploads
  stream separately from the prompt, are unlimited by default, and can still be
  capped explicitly with `CODEG_UPLOAD_MAX_ATTACHMENT_BYTES`. The prompt route
  accepts a 32 MiB JSON envelope for compatibility with older inline payloads.
- **Current Codex steering remains supported.** Codeg ships the upstream
  `codex-acp` 1.1.9 integration and keeps both native live-turn steering and the
  companion feedback fallback available without double-delivering a message.
- **PDFs and other standalone outputs appear under the producing reply.** An
  exclusive inferred output is promoted to the reply-tail primary output even
  when the agent did not explicitly declare it. Ambiguous or historical files
  remain in the inclusive conversation deliverables list instead of being
  attached to the wrong reply.
- **Cross-device output attribution is durable.** Prompt fingerprints and
  persisted turn links associate settled files with the correct user turn when
  another browser does not have the sender's optimistic message id. Both
  declaration and artifact-settlement events refresh remote and sub-agent
  transcript views.
- **Delivery failures are visible and recoverable.** Stable backend error codes,
  a longer remote prompt window, and a persistent send queue distinguish safe
  retries from uncertain delivery states.

Database migrations run automatically and add the nullable turn-link fields
required for cross-device deliverable attribution.

# Codeg v0.23.2 中文说明

## 同步上游、可靠发送远端消息、准确展示最终产物

Codeg v0.23.2 将定制版本完整 rebase 到上游 v0.23.1，并保留和增强远端会话与
成果物能力。

- **完整合入上游 v0.23.1。** 包含工作任务、自定义智能体与技能、工作区文件夹
  链接、最新的分屏/平铺对话界面，以及当前各代理的兼容性更新。
- **远端纯文字消息可可靠送达。** 前端会先等待事件流就绪；ACP 连接失效时自动
  恢复，并仅针对确定性的连接丢失使用同一个幂等消息 ID 重试。网络超时等不确定
  状态只做对账、不盲目重发，避免重复消息。
- **长图不再受旧上传上限影响。** 浏览器会把附件与消息分开流式上传，默认不限
  大小；如需限制，可设置 `CODEG_UPLOAD_MAX_ATTACHMENT_BYTES`。消息接口仍允许
  32 MiB JSON 请求体，以兼容旧版内联附件。
- **保留当前 Codex steering 支持。** 本版本采用上游 `codex-acp` 1.1.9，同时支持
  原生当前轮引导与伴生进程反馈回退，并避免同一条内容被重复投递。
- **PDF 等独立最终产物会显示在对应回复下方。** 即使代理没有显式声明，只要能
  唯一归属到该轮，推断出的独立输出也会提升为回复尾端的主要产物；归属不明确或
  历史文件只保留在左侧完整成果物列表，不会错误挂到某条回复。
- **跨机器成果物关联可持久化。** 提示词指纹和已落库的 turn 关联，在另一台浏览器
  缺少发送端临时消息 ID 时，仍能把已完成文件归到正确的用户轮次。成果物声明和
  文件落盘事件都会刷新远端及子智能体会话视图。
- **发送失败可见且可恢复。** 稳定的后端错误码、更长的远端发送等待窗口和持久化
  消息队列，可以区分“可安全重试”与“发送结果不确定”。

数据库迁移会自动执行，并加入跨设备成果物归属所需的可空 turn 关联字段。
