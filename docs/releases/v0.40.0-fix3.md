# v0.40.0-fix3

基于 upstream v0.40.0（`95fd81df4374753c460b5cb0ed01de8f1ea24702`）。

同一业务对话在 Codex、Claude Code、Pi 之间切换，保留统一 ID、历史、任务、附件、产物、
共享记忆和 Skill，每个引擎保留自己的原生 session、writer、认证、模型与参数。运行中
等轮边界交接，准备失败保留原会话，跨端 CAS、持久收据与有界增量避免串线或重复发送。
启用统一业务历史后，原生 session 自动标题不再改写业务标题；迟到的标题写入也受数据库
原子条件保护。空标题仍可由原始用户输入初始化，用户主动重命名保持有效，不改写其锁定状态。

隔离 Setup 重启验收另复现标签版本保存与后台历史写入的 SQLite WAL 锁竞争。
标签 CAS 事务先取得 writer 再读版本，首次保存及已有版本均能等待后台写入；
旧版本请求仍被拒绝，拒绝不推进版本或元数据时间，不靠重试掩盖错误。

Pi 原生 JSONL 身份与 ACP ID 分离校验，新建空会话先持久化，旧别名通过明确文件映射修复。
接通原生 steer、当前尾部 clone 和 Pi 1.4 原生 MCP，CodeG companion 提供真实子任务、
取消、结果回收与产物登记。SSE、任意旧 fork point、跨引擎无损原生上下文不支持；snapshot
fallback 明确标注。Pi 的 thinking 不等于 Plan，Pi 不广告原生 Plan/Goal。

新增以业务 conversation ID 为目标的持久外部投递接口，固定接收时 Agent/session/切换代次
与执行配置，支持约束、幂等键、附件、queue/steer、状态查询及取消。切换中明确拒绝重试，
配置变化明确失败，交付不确定窗口禁止自动重发。只新增迁移，不删除历史；没有修改或验证
2K 等外围程序。旧连接接口继续保留，拒绝过期或错配连接，调用方迁移说明见接口文档。

Pi GPT Responses 的 Fast / Speed 请求 `default` 或 `priority`，独立于推理强度、默认关闭、
按 session/模型/接口保存；运行中拒绝改档。不支持明确禁用，拒绝不悄悄降级。区分已请求、
中转返回和上游返回，缺证据保持未验证。可能增加额度/费用由当前供应商决定，不套用官方
倍率；真实中转及账号的实际档位、计费与速度未验证。

Server ZIP 和 Setup 同时携带匹配 MCP、私有 Node 24.16.0、Pi 1.4.0 与定制
pi-acp 0.0.34-codeg.2；版本来源、锁文件、逐文件 SHA256、许可证随包保留，不依赖全局旧版。
升级/回滚替换整组运行组件，保留用户历史、认证、配置、扩展和工作区。
构建时统一解析 Windows 临时目录映射后再验证 Node ZIP，保留越界与内部链接拦截。

验收使用真实 ACP/CLI 与隔离确定性模型端点，覆盖三引擎增量往返、共享内容实际收到、
初始化和恢复、故障回退、排队与并发、原生 MCP/子任务/产物、档位及外部投递。
Windows 一次性 runner 验证 Server Web、Setup WebView2、旧版安装升级、启动、资源、
依赖和迁移、整组旧包加离线快照回滚，以及重新下载的发布资产。确定性端点验证协议和传输，
不证明真实账号推理。

保留已发布的普通整轮耗时、直接执行／先规划／目标执行、总产物和虚拟列表滚动修复，
继续回归实时完成、历史、长列表和异步布局。总产物入口在右侧“会话详情 → 总产物”。
