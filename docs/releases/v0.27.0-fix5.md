# Codeg v0.27.0-fix5

## Reliable remote file downloads

- Keeps every attachment response, including `text/plain` and `text/csv`, out
  of the global Brotli/gzip middleware. Text deliverables now retain their
  exact source bytes and `Content-Length` across remote links.
- Marks file and archive responses as private, uncached, and `no-transform` so
  reverse proxies and CDNs do not rewrite one-time download streams.
- Publishes the source file size as download integrity metadata. The remote
  desktop client requests identity encoding and verifies the received byte
  count before replacing the destination file.
- A truncated or unexpectedly empty transfer now fails safely, removes only
  its temporary partial file, and preserves an existing destination. Genuine
  zero-byte source files remain valid downloads.

# Codeg v0.27.0-fix5 中文说明

## 远程文件下载可靠性

- 所有附件响应（包括 `text/plain` 和 `text/csv`）都不再进入全局 Brotli/gzip
  压缩中间件；文本产物经远程链路下载时会保持源文件的原始字节和准确长度。
- 文件和压缩包响应明确设置为私有、不缓存、`no-transform`，避免反向代理或 CDN
  改写一次性下载流。
- Server 随响应提供源文件大小；远程桌面端强制请求 identity 编码，并在替换目标文件前
  校验实际接收字节数。
- 截断或异常空响应会安全失败，只清理临时分片并保留已有目标文件；源文件本来就是
  0 字节时仍可正常下载。
