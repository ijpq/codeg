# Codeg v0.28.2-fix1

## Branch returns reuse durable deliverable identities

- Fixes branch returns that rolled back with SQLite error 2067 when the source
  conversation already contained the same deliverable path.
- Treats Windows slash style, drive-letter case, repeated separators, `.` and
  safely resolvable `..` components as one file identity. New records use a
  forward-slash storage form; legacy rows and files are not rewritten.
- Reuses or updates the source conversation's durable deliverable row and
  records the branch result as a new turn association, preserving version
  lineage without inserting a duplicate path.
- Keeps invalid, hidden, deleted and filtered inferred intermediate files out
  of the returned result. Explicit declarations remain authoritative.
- Stores source-conversation deliverable IDs in new merge audit rows while
  preserving compatibility with older and manually repaired merge records.
- Adds transaction-stage, SQLite error-kind and constraint diagnostics. The
  client now renders a stable structured error code instead of
  `[object Object]`, keeps failed branches visible, and prevents duplicate
  submissions while a return is in progress.

No database migration is required. Existing duplicate path spellings remain
auditable and are resolved by normalized identity on read/write; no user file,
conversation, Codex rollout or previous merge record is modified automatically.

The Windows Setup and Server Web packages contain the same updated interface.

# Codeg v0.28.2-fix1 中文说明

## 分支回归复用主会话的持久产物身份

- 修复主会话已存在同路径产物时，分支回归因 SQLite 2067 唯一约束而整体回滚的
  问题。
- Windows 路径的正反斜杠、盘符大小写、重复分隔符、`.` 以及可安全解析的 `..`
  统一视为同一文件；新记录统一使用正斜杠，旧记录和磁盘文件不会被批量改写。
- 复用或更新主会话已有的持久产物记录，并用新的轮次关联保存本次分支版本，既保留
  追溯关系，也不再插入重复路径。
- 无效、隐藏、删除及被现有规则过滤的自动推断中间文件不会被回传；显式登记仍为最高
  优先级。
- 新的 merge 审计记录保存主会话产物 ID，同时兼容旧版及人工安全修复过的合并记录。
- 增加事务阶段、SQLite 错误类型和约束名日志；前端显示稳定的结构化错误码，不再出现
  `[object Object]`，失败时保留分支，并在回归进行中阻止重复提交。

本版本不需要数据库迁移。历史路径别名继续保留以供审计，通过规范化身份进行查重；不会
自动修改用户文件、会话、Codex rollout 或既有 merge 记录。

Windows Setup 与 Server Web 使用同一套更新后的前端资源。
