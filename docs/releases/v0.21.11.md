# Codeg v0.21.11

## CI-verified deliverables patch release

Codeg v0.21.11 supersedes v0.21.10 with the same deliverables
reconciliation functionality plus a corrected cross-platform integration test
suite. Use v0.21.11 when installing or referencing this release line so the
published tag corresponds to a fully green CI run.

- **Cross-platform test fixtures are synchronized.** Unix and Windows
  delegation integration stubs now implement the idempotent
  `publish_deliverables` interface, including its request ID and structured
  argument envelope.
- **The complete request model is covered.** End-to-end tests now populate turn
  expectations, request envelopes, deliverable categories, and change kinds
  introduced by the reconciliation release.
- **Replacement behavior is exercised explicitly.** The Unix socket
  integration test publishes with distinct idempotency keys and explicit
  `replace` mode, verifying that the second declaration replaces only the
  active turn's deliverables.
- **The full CI matrix is green.** Frontend checks and Rust desktop/server jobs
  pass on Linux, macOS, and Windows, including full desktop tests and strict
  Clippy checks.

The runtime deliverables improvements from v0.21.10 remain included: code
changes are publishable outputs, every turn receives deterministic settlement,
declarations use durable idempotency and retry handling, prompt-named paths
improve attribution, and caches or temporary intermediates remain excluded.

The database migration is applied automatically on startup.

# Codeg v0.21.11 中文说明

## 通过完整 CI 验证的产物交付补丁版

Codeg v0.21.11 在保留 v0.21.10 全部 deliverables 结算功能的基础上，
修复了跨平台集成测试未同步新接口的问题，并取代 v0.21.10。安装或引用这一
版本线时应使用 v0.21.11，确保发布标签对应完整通过 CI 的提交。

- **同步跨平台测试夹具。** Unix 与 Windows 委托集成测试的 stub 现已实现带
  request ID 和结构化参数 envelope 的幂等 `publish_deliverables` 接口。
- **覆盖完整请求模型。** 端到端测试现会填写本次结算功能新增的 turn 预期、
  请求 envelope、产物分类和变更类型字段。
- **显式验证替换语义。** Unix socket 集成测试使用两个不同的幂等 ID 和明确的
  `replace` 模式，验证第二次声明只替换当前 turn 的产物。
- **完整 CI 矩阵通过。** 前端检查以及 Linux、macOS、Windows 上的 Rust
  desktop/server job 全部通过，包括完整 desktop tests 和严格 Clippy。

v0.21.10 引入的运行时能力全部保留：代码修改可作为产物发布、每个 turn 都会
确定性结算、显式声明支持持久化幂等与重试、prompt 中点名的路径改善归属判断，
同时继续排除缓存和临时中间文件。

数据库迁移会在启动时自动执行。
