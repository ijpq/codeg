# Codeg v0.30.5-fix2

本版本将定制分支从 v0.29.0-fix1 升级到上游稳定版 v0.30.5，并保留会话分支、
Codeg MCP、产物追踪、Web 引用、模型隔离和大历史分页等定制能力。

## 上游同步与 Codex

- 合并上游 v0.30.0 至 v0.30.5，包括会话画布、多智能体、Codex 原生分支、后台终端、
  运行中消息投递、附件恢复、分支状态恢复、Astra 支持以及上下文压缩状态显示。
- Codex ACP 锁定为上游验证的 1.10.0；兼容当前稳定 Codex CLI 0.153.4。
- 保留 `gpt-6-astra`、`gpt-5.6-sol`、`gpt-5.6-luna` 目录能力，并按当前会话实际暴露的
  MCP 工具动态启用异步提问等能力。
- 上下文界面优先显示运行时返回的有效窗口、压缩阈值和使用比例，并标明运行时来源；
  切换模型后重新解析有效参数。

## 超大历史与恢复

- Codex rollout 首屏继续使用有界游标、持久化增量字节索引和后台续建，不完整状态明确
  标为 `missing`、`building`、`limited`、`stale` 或 `corrupt`。
- 尾部扫描从 16 MiB 自适应增长，硬上限为 64 MiB；跨分片巨型 JSONL 记录只拼接一次，
  避免重复复制和重复扫描。
- 索引记录规范路径、文件标识、观测文件大小与修改时间、字节水位、条目数量和完整性；
  追加、替换、损坏和落后水位均会重新验证或续建。
- 数据库消息与 rollout 消息按稳定时间和来源顺序合并；后台完成结果会持久化，并在重新
  打开会话后通过补偿查询恢复。
- 3.506 GB 稀疏合成 rollout 的最新页解析为 547 ms，仅扫描 3 MiB；内存缓存重开为
  1 ms，持久化索引重开为 165 ms 且扫描 0 字节。返回 JSON 约 3.08 MB，gzip 为
  4,484 字节，峰值 RSS 约 157 MiB。
- 20 MiB 巨型单条 JSONL 场景解析为 1.56 s，扫描 20,977,304 字节，峰值 RSS 约
  157 MiB，仍低于 64 MiB 硬上限。

## 页面生命周期与慢分支

- 页面切换、路由变化和浏览器临时断线只取消前端订阅，不会自动终止服务端任务。
- 重连恢复使用 single-flight、generation、request ID 和事件补偿，丢弃晚到的旧结果，
  防止重复 writer、重复事件流和重复提交。
- 慢分支创建改为数据库持久化任务，提供 `queued`、`running`、`succeeded`、`failed`、
  `cancelled` 状态以及稳定幂等键。普通 HTTP 超时或断线后继续查询同一任务。
- 服务进程重启后，属于旧进程且无法安全续跑的 `running` 任务会收敛为
  `failed/interrupted`，并提示先检查是否已产生分支，再用新请求 ID 重试。

## 保留的定制增强

- 扁平工作区和 Full Access 权限映射。
- Codeg MCP 的 deliverables、feedback、ask、sessions 与异步委托能力。
- native fork、分支合并/回退、原会话保护和分支继承边界。
- Web citation 元数据桥接、产物识别/登记、可见输出关联和历史产物按需加载。
- 本地模型目录、按模型参数隔离、断线消息队列和后台任务恢复。

## 已知限制

- 单条 JSONL 记录超过 64 MiB 且所需轮次完全位于该记录之前时，首屏会明确显示索引受限
  或重建中，待后台索引到达后恢复；不会越过硬上限解析整份 rollout。
- 分支任务进入不可安全中断的 ACP 原生 fork 阶段后，取消会记录为请求中并等待操作到达
  真实终态，避免留下半创建分支。
- 本仓库构建环境无法访问生产 Windows 主机上的 `LOCAL_CUSTOMIZATIONS.md`、守护脚本和
  计划任务；这些机器级文件未写入发布包，也没有在本次源码发版中被修改。
