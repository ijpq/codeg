# Codeg v0.21.14

## Reliable remote prompts and accurate deliverables

Codeg v0.21.14 fixes prompt delivery from remote browsers and makes the
artifacts shown beside each reply match that turn more precisely.

- **Remote text prompts recover from stale connections.** The web client waits
  for its event stream before submitting, allows slow workspace startup up to
  120 seconds, and restores a vanished ACP connection before retrying the same
  idempotent message once. Ambiguous network timeouts are never retried, so an
  accepted prompt cannot be duplicated.
- **Connection failures are explicit.** Missing connections and exited agent
  processes now return stable `connection_not_found` and `process_exited`
  errors, allowing the client to distinguish safe recovery from an uncertain
  delivery state.
- **Long image prompts are accepted.** The ACP prompt route now allows request
  bodies up to 32 MiB, including the base64 expansion of a 1,687,739-byte image.
- **Codex CLI 1.1.7 steering is supported.** Codeg negotiates the native
  `_session/steering` protocol used by current `codex-acp`, preserves the legacy
  `session/steer` fallback, and reports whether steering continued the current
  turn or started a new one.
- **Reply artifacts are precise.** The artifact strip below a reply shows only
  primary standalone outputs for that turn, while the conversation-level
  deliverables panel remains an inclusive, filterable ledger of source, test,
  configuration, and output changes.
- **Cross-device artifact links are durable.** A prompt fingerprint ties
  completed runs to the correct user turn even when optimistic browser message
  ids are unavailable on another machine. Artifact settlement events also
  refresh remote clients after inference is committed.
- **Sub-agent outputs follow the same rules.** Declared and inferred
  deliverables are normalized consistently in the sub-agent session dialog,
  including missing or deleted output diagnostics where appropriate.

This release includes an automatic database migration that adds the nullable
`prompt_fingerprint` column to conversation turn runs.

# Codeg v0.21.14 中文说明

## 远端消息可靠发送与准确的成果物展示

Codeg v0.21.14 修复了远端浏览器消息未真正送达的问题，并让每条回复下方展示的
成果物更准确地对应本轮对话。

- **远端纯文字消息可从失效连接自动恢复。** Web 客户端会先等待事件流就绪，给
  较慢的工作区启动最多 120 秒；如果 ACP 连接已消失，则恢复连接，并使用同一个
  幂等消息 ID 重试一次。网络超时等不确定错误不会自动重试，避免重复发送。
- **连接故障具备明确错误码。** 连接不存在和代理进程退出分别返回稳定的
  `connection_not_found`、`process_exited`，前端可以区分“可安全恢复”和“发送状态
  不确定”。
- **支持长图消息。** ACP 消息接口的请求体上限提高到 32 MiB，能够容纳
  1,687,739 字节图片经过 base64 编码后的体积。
- **兼容 Codex CLI 1.1.7 的 steering。** Codeg 会协商新版 `codex-acp` 使用的原生
  `_session/steering` 协议，同时保留旧版 `session/steer` 回退，并正确区分继续当前
  turn 和新建 turn。
- **回复下方成果物更准确。** 每条回复尾部只显示属于该轮的主要独立产物；左侧
  对话级成果物面板仍保留完整、可筛选的源码、测试、配置和输出变更清单。
- **跨机器成果物关联可持久化。** 新增提示词指纹，即使另一台机器没有浏览器端的
  临时消息 ID，也能把已完成 run 关联到正确的用户消息；推断落库后还会通过成果物
  结算事件刷新远端客户端。
- **子智能体产物采用相同规则。** 子智能体会话弹窗统一规范化声明与推断产物，并
  在适当情况下保留缺失或已删除产物的诊断信息。

本版本包含自动数据库迁移：为对话 turn run 新增可空的 `prompt_fingerprint` 字段。
