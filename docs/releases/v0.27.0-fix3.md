# Codeg v0.27.0-fix3

## Unified, recoverable conversation branches

- Unifies Create Branch, Fork & Send, and message-point branching on one
  idempotent branch service, with consistent numbered titles and immutable
  source/session mappings.
- Retires the native-fork adapter after `session/fork`, then verifies the child
  on an independent ACP process. This releases the source session writer and
  prevents the original conversation from becoming stuck during restore.
- Composes the source transcript through the fixed fork point with branch-local
  turns, so native and snapshot branches both show their inherited history
  without copying the source rows or leaking later source messages.
- Persists branch creation and first-message queues across reloads, and repairs
  legacy provisional or incomplete branch lifecycle records without deleting
  sessions or conversation history.
- Makes Return to Source a one-click, append-only, idempotent merge of all
  branch-local visible results, valid deliverables, and file changes. A merged
  branch becomes read-only and leaves active lists while remaining auditable.
- Adds recovery single-flight by external session, legacy active-writer
  handoff, generation-safe frontend convergence, and migration coverage for
  half-created and already-merged branches.

# Codeg v0.27.0-fix3 中文说明

## 统一且可恢复的对话分支

- 将“创建分支”“分叉发送”和“从消息创建分支”统一到同一个幂等分支服务，使用一致的
  自动编号标题，并保持源对话与 session 映射不变。
- 原生 `session/fork` 完成后主动退出执行分叉的适配器，再用独立 ACP 进程验证子
  session，从而释放源 session 的 writer，避免原对话恢复时长期卡在初始化状态。
- 按固定分叉点组合源对话历史与分支新增消息；原生分支和快照分支都能显示继承历史，
  无需复制源消息记录，也不会混入分叉后的源对话消息。
- 分支创建与首条消息队列可跨刷新保存；兼容修复旧版 provisional、半完成分支状态，
  不删除原始 session 或会话历史。
- “回归主会话”改为一键、追加式、幂等合并，自动回传分支新增的可见结果、有效产物和
  文件变更；成功后分支只读并退出活动列表，但底层审计记录继续保留。
- 增加基于 external session 的恢复 single-flight、旧 active writer 受控交接、前端
  generation 收敛，以及半完成/已合并分支的迁移测试。
