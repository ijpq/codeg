# Codeg v0.28.1-fix4

## Dated branches from the conversation sidebar

- Adds **Create branch** to the context menu of each conversation in the left
  sidebar, so a branch can be created without opening the conversation first.
- Reuses the same durable queue, selector inheritance and idempotency path as
  the existing conversation-header action instead of introducing a separate
  branch implementation.
- Names new branches by the Codeg host's local date, for example
  `Topic · 分支 8.25`, with additional branches from the same source on that
  date named `Topic · 分支 8.25.2`, `.3`, and so on.
- Keeps existing branch titles unchanged and requires no database migration.

The Windows Setup and Server Web packages contain the same updated interface.

## Prompt terminal convergence

- Fixes Codex turns that already produced a final answer and
  `turn/completed` but remained in **Generating** while the optional AIR file
  change audit ran.
- The adapter now returns the authoritative ACP prompt terminal immediately;
  the file-change audit continues as an auxiliary task and is correlated back
  to the durable turn-run ID when it arrives.
- Durable turn completion, frontend terminal events, and artifact settlement
  remain separate and idempotent. A late or unavailable audit falls back to the
  existing workspace watcher without delaying the next prompt.
- Adds structured timestamps for prompt dispatch, ACP terminal receipt,
  durable terminal persistence, and artifact settlement to make future delays
  attributable without logging user content.

# Codeg v0.28.1-fix4 中文说明

## 从左侧会话列表创建日期分支

- 左侧会话的右键菜单新增“创建分支”，无需先打开会话即可直接操作。
- 与右上角现有入口共用同一套持久队列、模型配置继承和幂等创建逻辑，不增加平行的分支实现。
- 新分支按 Codeg 主机本地日期命名，例如 `主题 · 分支 8.25`；同一来源会话在当天创建的
  后续分支依次为 `主题 · 分支 8.25.2`、`.3`。
- 已有分支名称保持不变，不需要数据库迁移。

Windows Setup 与 Server Web 使用同一套更新后的前端资源。

## Codex 轮次结束状态及时收敛

- 修复 Codex 已输出最终回答并产生 `turn/completed` 后，仍因可选 AIR
  文件变更审计而长时间显示“生成中”的问题。
- 适配器现在立即返回权威 ACP 终止结果；文件审计作为独立附属任务继续执行，完成后按
  持久化的 `turn_run_id` 精确回补。
- 轮次完成、前端终止事件和产物结算继续保持解耦与幂等；审计迟到或不可用时回退到现有
  工作区监听，不阻塞下一条消息。
- 新增 prompt 发出、ACP 终止到达、数据库终态持久化、产物结算四阶段结构化耗时日志，
  不记录用户正文。
