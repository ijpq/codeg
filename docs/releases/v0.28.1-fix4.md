# Codeg v0.28.1-fix4

## Dated branches from the conversation sidebar

- Adds **Create branch** to the context menu of each conversation in the left
  sidebar, so a branch can be created without opening the conversation first.
- Reuses the same durable queue, selector inheritance and idempotency path as
  the existing conversation-header action instead of introducing a separate
  branch implementation.
- Names new branches by the Codeg host's local date, for example
  `Topic · 分支 8.25`, with additional branches from the same source on that
  date named `Topic · 分支 8.25.2`, `.3`, and so on.
- Keeps existing branch titles unchanged and requires no database migration.

The Windows Setup and Server Web packages contain the same updated interface.

# Codeg v0.28.1-fix4 中文说明

## 从左侧会话列表创建日期分支

- 左侧会话的右键菜单新增“创建分支”，无需先打开会话即可直接操作。
- 与右上角现有入口共用同一套持久队列、模型配置继承和幂等创建逻辑，不增加平行的分支实现。
- 新分支按 Codeg 主机本地日期命名，例如 `主题 · 分支 8.25`；同一来源会话在当天创建的
  后续分支依次为 `主题 · 分支 8.25.2`、`.3`。
- 已有分支名称保持不变，不需要数据库迁移。

Windows Setup 与 Server Web 使用同一套更新后的前端资源。
