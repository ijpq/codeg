# Codeg v0.28.1-fix3

## Reliable transcript bottom geometry

- Replaces the previous `scrollTop === scrollHeight - clientHeight` assumption
  with a stable, non-virtualized end sentinel and real DOM geometry checks for
  the final rendered message row.
- Detects and compensates when asynchronous Markdown, tool cards, images,
  deliverables or font layout make the last virtual row taller than the
  virtualizer's current declared height.
- Measures the complete composer dock with `ResizeObserver`, including queue,
  permission/plan, feedback, retry, failure and editor surfaces. Normal-flow
  docks shrink the transcript naturally; an actual overlap is cleared by its
  measured geometry rather than a fixed padding guess.
- Coalesces streaming, resize, zoom and asynchronous layout changes into one
  animation-frame correction, scoped to the current conversation generation so
  delayed work from a previous tab cannot move the new transcript.
- Keeps following while the reader is near the latest message, stops when the
  reader deliberately scrolls upward, and resumes through the existing
  “back to latest” control.
- Adds browser geometry coverage at 80%, 100%, 125% and 150% zoom, dynamic
  editor/queue heights, asynchronous tool/deliverable mounting, virtualizer
  under-measurement and reader escape behavior.

No database or backend protocol migration is required. The same exported web
assets are used by Windows Setup and Server Web.

# Codeg v0.28.1-fix3 中文说明

## 可靠的对话底部几何定位

- 不再把 `scrollTop === scrollHeight - clientHeight` 当作“最后一行已经可见”的
  充分条件；新增不参与虚拟化的稳定尾部锚点，并检查最后一条消息的真实 DOM 边界。
- Markdown、工具卡片、图片、产物或字体异步布局导致最后一个虚拟行高暂时低估时，按实际
  像素差动态补偿，避免滚动条已经到底但末行仍被裁切。
- 使用 `ResizeObserver` 测量整个输入区，包括队列、权限/计划、反馈、重试、失败提示和
  编辑器。正常文档流由布局自然缩小消息区；确有覆盖时按真实遮挡高度处理，不使用固定
  `padding-bottom` 猜测。
- 流式内容、窗口缩放和异步挂载统一合并到单帧校正，并按会话代际隔离；切换会话后，旧
  回调不能再操作新会话的滚动容器。
- 用户位于底部附近时继续自动跟随；主动向上阅读后不强制拉回，点击既有“回到最新消息”
  后恢复跟随。
- 浏览器实测覆盖 80%、100%、125%、150% 缩放、输入框与队列动态高度、工具/产物异步
  挂载、虚拟列表高度低估和用户向上阅读场景。

本版本不需要数据库或后端协议迁移。Windows Setup 和 Server Web 使用同一套已修复的
前端静态资源。
