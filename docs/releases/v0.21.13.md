# Codeg v0.21.13

## Fast remote startup with many open conversations

Codeg v0.21.13 completes the remote-history optimization started in v0.21.12.
It reduces browser initialization work when the desktop client has many open
conversation tabs and the same workspace is opened through the web service.

- **Hidden conversation UI is suspended.** In the normal single-tab layout,
  inactive tabs retain only their lightweight controller. Their message thread,
  rich Tiptap composer, skill/expert hooks, dialogs, and other expensive UI are
  unmounted until the tab becomes visible.
- **Background agents keep working.** Connection ownership, queues, live event
  handling, turn completion, and runtime state remain mounted for every open
  tab. Suspending the UI does not cancel a running agent or discard its
  background work.
- **Visible tiles remain live.** Tiled layouts continue to render and load every
  visible conversation while using the active tile for focus and input.
- **Drafts survive immediate tab switches.** Plain-text draft state is updated
  synchronously on every edit, and the complete Tiptap document is flushed on
  blur. A switch within the existing 300 ms rich-document debounce window
  cannot lose the user's latest typing.
- **The upstream v0.21.9 release is included.** This release contains upstream
  release commit
  [`e540a4fa`](https://github.com/xintaofei/codeg/commit/e540a4fa75cb739db319fa8ce9482690c8be8e57),
  including Codex sandbox and approval settings, expanded ACP filesystem
  policies, corrected Codex delegation result parsing, safer diff teardown,
  collapsible long commit messages, workspace visual fixes, OpenCode 1.18.5,
  and Grok 0.2.112. See the
  [upstream v0.21.9 notes](https://github.com/xintaofei/codeg/releases/tag/v0.21.9).
- **Regression coverage is included.** Tests verify the visible-content gate,
  controller-before-content ordering, immediate draft survival, and the
  combined upstream/fork frontend and Rust behavior.

This release does not introduce a database migration.

# Codeg v0.21.13 中文说明

## 大量打开对话时更快的远程启动

Codeg v0.21.13 完成了 v0.21.12 开始的远程历史优化。当桌面客户端打开了大量
对话标签，并通过 Web Service 访问同一工作区时，浏览器初始化工作量会显著降低。

- **挂起隐藏对话的重型 UI。** 普通单标签布局中，非活动标签只保留轻量
  controller；消息列表、Tiptap 富文本输入框、技能/专家 hooks、对话框等昂贵组件
  会卸载，直到标签重新变为可见。
- **后台智能体继续运行。** 所有打开标签仍保留连接所有权、消息队列、实时事件、
  turn 完成处理和 runtime 状态。挂起 UI 不会取消正在运行的智能体，也不会丢弃
  后台任务。
- **可见分屏保持实时。** Tile 布局仍会渲染和加载每个可见对话，并继续以活动
  tile 处理焦点和输入。
- **快速切换标签也不会丢草稿。** 每次编辑都会同步更新轻量文本草稿缓存，失焦时
  立即保存完整 Tiptap 文档；即使在原有 300ms 富文档防抖窗口内切换标签，也不会
  丢失最后输入的内容。
- **包含上游 v0.21.9 release。** 本版本包含上游 release commit
  [`e540a4fa`](https://github.com/xintaofei/codeg/commit/e540a4fa75cb739db319fa8ce9482690c8be8e57)，
  包括 Codex 沙箱与授权设置、扩展后的 ACP 文件系统策略、Codex 委派结果解析修复、
  更安全的 diff 销毁顺序、长 commit 信息折叠、工作区视觉修复，以及
  OpenCode 1.18.5 和 Grok 0.2.112。完整内容参见
  [上游 v0.21.9 说明](https://github.com/xintaofei/codeg/releases/tag/v0.21.9)。
- **补充回归覆盖。** 测试会验证可见内容 gate、controller 先于内容 gate 的顺序、
  快速挂起时的草稿保留，以及合并上游后前端和 Rust 的整体行为。

本版本不包含数据库迁移。
