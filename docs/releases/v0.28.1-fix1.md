# Codeg v0.28.1-fix1

## Codex internet citations

- Rebases the CodeG fork onto upstream `v0.28.1` while preserving the existing
  branch, restore, steering, deliverable, chat-channel, and remote-use features.
- Preserves Codex app-server `WebSearchItem.results` through the pinned
  `codex-acp` 1.6.2 adapter instead of dropping citation reference-to-URL data.
- Stores structured citation sources in existing tool metadata, keeping live
  WebSocket rendering and persisted rollout history on the same data path
  without a database migration.
- Renders safe HTTP(S) sources as numbered links with title and domain,
  deduplicates repeated sources, and exports readable URLs when copying text or
  forwarding a final answer to a plain-text chat channel.
- Keeps unresolved legacy markers visible as “引用来源暂不可解析”; CodeG never
  hides the missing source or invents a URL when the old rollout has no mapping.
- Preserves resolved source URLs when creating snapshot-based conversation
  branches and rejects unsafe or malformed citation URLs.

# Codeg v0.28.1-fix1 中文说明

## Codex 互联网引用

- 将 CodeG fork 同步到 upstream `v0.28.1`，并保留既有分支、恢复、引导、产物、
  聊天通道和远程使用增强。
- 在锁定的 `codex-acp` 1.6.2 适配层保留 Codex app-server
  `WebSearchItem.results`，不再丢弃引用 ID 到网址的映射。
- 引用来源复用现有工具元数据持久化；WebSocket 实时显示与 rollout 历史恢复走同一
  数据链，不需要数据库迁移。
- 有效 HTTP(S) 来源显示为带标题和域名的编号链接；重复来源复用编号，复制正文和微信等
  纯文本通道会附带可理解的网址。
- 旧会话若从未保存来源映射，会明确显示“引用来源暂不可解析”；不隐藏标记，也不伪造网址。
- snapshot 分支会保留已解析的来源网址，并拦截恶意协议和无效 URL。
